=============================================================================
CE QUI SE PASSE
=============================================================================

1. Vous entrez email + mot de passe dans l'app Flutter
2. Flutter envoie les données au backend (POST /auth/login)
3. Backend vérifie dans MySQL :
   - Table acces_app : vérification du mot de passe (bcrypt)
   - Table users : récupération du nom/prénom
4. Si OK : Backend renvoie un token JWT + infos utilisateur
5. Flutter affiche : "BRAVO ! Vous avez réussi" + votre nom
6. Si KO : Message d'erreur "Identifiants invalides"
